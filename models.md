# Models
This documents provides an overview of all used models and where they should be placed.
All models are present on the VNC on their respected locations, they are listed below.
## Computer vision
### YOLO
The checkpoint should placed in directory ``app/resources``.
### Lane detection
The checkpoint for Ultra Fast Structure-aware Deep Lane Detection should be placed in directory ``app/data_processors/model``.

### Traffic sign
The checkpoint should be placed in directory ``app/data_processors/model``.

### Traffic light
The checkpoint should be placed in directory ``app/TrafficLights/Models``.

## Reinforced Learning
Models should be placed in directory ``ACC/Agents/models``.
